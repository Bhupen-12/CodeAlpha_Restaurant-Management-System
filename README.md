# Restaurant Management System

A Restaurant Management System built using Django and Django REST Framework.

## Features

- View restaurant menu
- Place food orders
- Reserve tables
- Manage inventory
- Admin panel
- REST APIs

## Technologies

- Python
- Django
- Django REST Framework
- SQLite

## Installation

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Visit:

```
http://127.0.0.1:8000/api/
```
